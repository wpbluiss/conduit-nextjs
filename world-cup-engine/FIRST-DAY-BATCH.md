## How to post each (phone, ~2 min)
1. Tap the video link → press-and-hold → **Save to camera roll** (or Download).
2. YouTube app → **+ (Create)** → **Create a Short** → pick the clip.
3. Tap the clip's audio → set **original volume to 0** (kills the AI ambient).
4. Tap **Add sound** → search a trending track matching the vibe above → add it.
5. Paste the caption, set the title, tap **Post** (or schedule).
6. Space the 3 a few hours apart (e.g., morning / afternoon / evening).
